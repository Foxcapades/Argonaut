= Flag Inheritance
:source-highlighter: highlightjs

Demonstration of flag inheritance in rendered help text.

== Flag Inheritance Enabled

.Show help for the tree root
[source, bash]
----
go run enabled.go --help
----

[source]
----
Usage:
  enabled [options] <command>

Commands
  foo

Flags
  -a | --apple
      The apple flag.
  -b | --banana
      The first banana flag.
  -c | --cantaloupe
      The cantaloupe flag.
  -d | --durian
      The first durian flag.
  -h | --help
      Prints this help text.
----

.Show help for the first level subcommand
[source, bash]
----
go run enabled.go foo --help
----

[source]
----
Usage:
  enabled foo [options] <command>

Commands
  bar

Flags
  -a | --acorn
      The acorn flag.
  -n | --banana
      The second banana flag.
  -h | --help
      Prints this help text.

Inherited Flags
  --apple
      The apple flag.
  -b
      The first banana flag.
  -c | --cantaloupe
      The cantaloupe flag.
  -d | --durian
      The first durian flag.
----

.Show help for the leaf subcommand
[source, bash]
----
go run enabled.go foo bar --help
----

[source]
----
Usage:
  enabled foo bar [options]

Flags
  -c | --cabbage
      The cabbage flag.
  -u | --durian
      The second durian flag.
  -h | --help
      Prints this help text.

Inherited Flags
  -a | --acorn
      The acorn flag.
  -n | --banana
      The second banana flag.
  --apple
      The apple flag.
  -b
      The first banana flag.
  --cantaloupe
      The cantaloupe flag.
  -d
      The first durian flag.
----
